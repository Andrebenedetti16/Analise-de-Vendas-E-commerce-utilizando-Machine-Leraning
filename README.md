# Analise-de-Vendas-E-commerce-utilizando-Machine-Leraning
#3️⃣ Vendas E-commerce com Machine Learning 🛍️🤖
📌 Visão Geral
Este projeto aplica técnicas de Machine Learning para prever vendas em um e-commerce, analisando comportamento de compra, sazonalidade e desempenho de produtos.

📊 Objetivos
Prever vendas futuras com modelos supervisionados

Avaliar métricas de performance (RMSE, MAE, R²)

Otimizar decisões de estoque e marketing

🧠 Algoritmos Usados
Regressão Linear

Random Forest

XGBoost

🛠️ Tecnologias
Python

Scikit-learn

Pandas / Seaborn / Plotly

Jupyter Notebook
